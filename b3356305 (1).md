# Ab Initio Manifest Parser Skeleton

This skeleton implements the **manifest-first, file-only** architecture.

## Modules
- `inventory.py`: repository and artifact discovery
- `resolver.py`: parameter source loading and precedence resolution
- `manifest_builder.py`: lineage/test-case manifest emission
- `abinitio_manifest_cli.py`: thin CLI entry point
- `__init__.py`: package exports

## Current status
This is a **skeleton**, not the final parser. It provides:
- data models
- output directory creation
- inventory scanning
- basic parameter-source registration
- manifest file writers
- placeholder hooks for graph/DML/MFS/Autosys parsing

## Example
```bash
python abinitio_manifest_cli.py   --sandbox-parent /repo/project   --parameter-path /etc/profile.d   --parameter-path ~/.kshrc   --output ./output_root
```
